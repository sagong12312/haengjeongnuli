# 행정누리

통합 행정업무 시스템 **행정누리**의 화면 시안 저장소입니다.

## 화면 시안 (`design/`)

| 파일 | 화면 |
|---|---|
| `Main.dc.html` | 메인메뉴 (출근 상태 인사말, 업무 메뉴, 나의 할 일, 공지사항) |
| `Approval.dc.html` | 전자결재 (문서함, 결재 문서 목록) |
| `Draft.dc.html` | 기안하기 (결재선, 문서 정보, 비공개 사유, 수신·경유·참조, 발신 명의) |
| `Civil.dc.html` | 민원 (처리 현황, 민원 종류별 처리기간, 민원 목록) |
| `CivilNew.dc.html` | 민원 접수 (창구 직원 전용, 처리기한 계산, 민원인 연락처) |
| `Finance.dc.html` | 재정·세무 (예산 집행, 지출결의 / 부과·징수, 부과 내역) |
| `Hr.dc.html` | 인사 (내 인사정보, 출퇴근, 복무 신청, 연가) |
| `Board.dc.html` | 게시판 (공지사항·건의사항·자료실) |
| `Write.dc.html` | 게시판 글쓰기 |
| `Upload.dc.html` | 자료실 자료 올리기 |
| `canvas.json` | 캔버스 배치 정보 |

### 참고

- `.dc.html` 파일은 Claude 디자인 캔버스 형식이라, 브라우저에서 바로 열면 화면이 그려지지 않습니다. 실제 화면 구현 시 구조와 스타일을 참고하는 원본으로 사용합니다.
- 공통 디자인: 테마색 남색 `#1D4E89`, 글꼴 문체부 돋음체(MDotum). 글꼴 파일은 이용 조건(재배포 허용 여부)을 확인하지 못해 저장소에 포함하지 않았습니다.
- 이름·번호·금액 등 실제 데이터는 `[대괄호]` 자리표시자로 비워 두었습니다.
- 민원 처리기간, 보존기간, 정보공개법 비공개 사유 등 법령 관련 문구는 검색 자료 기준이며, 국가법령정보센터 원문으로 최종 확인이 필요합니다.
