보안 프로그램 안내 관리

유해사이트 차단 (악성·도박·성인 사이트) 설정

업무용 PC·민원인 PC에 설치할 보안 프로그램과 내려받는 곳을 적습니다. 강제 항목을 설치하지 않은 직원은 행정누리 업무 화면을, 민원인은 전자민원을 쓸 수 없습니다. 권고 항목은 안내만 합니다. 휴대폰·태블릿으로 전자민원에 들어오는 민원인은 PC 용 프로그램을 설치할 수 없으므로 강제 항목으로 막지 않습니다. 국민이 쓰는 전자민원에는 강제 설치를 되도록 피하세요 (정부 방침은 공공 누리집에서 플러그인을 걷어 내고, 보안 프로그램 설치는 이용자가 고르게 하는 것). 새 판을 배포했거나 다시 설치하게 할 때는 다시 확인 요청을 누르면 모든 직원의 확인이 초기화됩니다. 실제 설치 여부는 기관의 PC 보안 점검 도구(예: 내PC지키미, 패치관리시스템)로 따로 확인하세요.
