유해사이트 차단 (직원 업무용 PC)

행정누리 화면은 브라우저가 다른 사이트에 가는 것을 직접 막을 수 없습니다. 그래서 여기서 정한 목록으로 차단 스크립트를 만들어 직원 PC에 깝니다. 스크립트는 ① 거르는 DNS로 바꾸고(악성코드·성인 사이트), ② Chrome·Edge 정책으로 아래 목록의 사이트(하위 주소 포함)를 막고 DNS-over-HTTPS를 끄며, ③ hosts 파일에도 목록을 넣습니다. 강제 보안 프로그램으로 등록하면 스크립트를 설치하지 않은 직원은 행정누리를 쓰지 못합니다. 기관 방화벽·DNS에서 함께 거르면 더 확실합니다 (PC 관리자 권한이 있는 직원은 스스로 풀 수 있음).
