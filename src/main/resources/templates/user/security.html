2단계 인증 (휴대폰 인증 앱)

비밀번호가 새어 나가도 휴대폰 인증 앱의 6자리 번호가 없으면 로그인할 수 없게 합니다. 개인정보를 다루는 직원은 켜 두기를 권합니다.

시스템 관리자는 2단계 인증을 켜야 합니다 (기관 설정).

켜짐 로그인할 때 인증 앱의 번호도 넣습니다.
  1. 휴대폰에 인증 앱(Google Authenticator 또는 Microsoft Authenticator)을 설치합니다.
  2. 앱에서 '설정 키 입력'을 고르고 계정 이름은 행정누리, 키는 아래 글자를 그대로 넣습니다 (시간 기준).
    ABCD EFGH
    휴대폰으로 이 화면을 보고 있다면 여기를 눌러 앱에 바로 추가할 수도 있습니다.
  3. 앱에 나온 6자리 번호를 넣고 '켜기'를 누릅니다.

이 키는 다른 사람에게 보여 주지 마세요. 켜기 전까지는 로그인에 쓰이지 않습니다.

비밀번호 규칙

  • 9자 이상, 영문·숫자·특수문자를 모두 섞고, 아이디를 넣을 수 없습니다.
  • password·qwer·1234처럼 흔한 낱말이나 이어지는 숫자, 같은 글자 4번 반복은 쓸 수 없습니다.
  • 재사용
  • 처음 보는 주소에서 로그인하면 알림이 옵니다. 오래 쓰지 않은 계정은 자동으로 사용 중지됩니다.
